# 幕里安卓安装说明（2.16.12）

电视、电视盒子使用 `幕里-AndroidTV-2.16.12.apk`；安卓手机、平板使用 `幕里-Android-2.16.12.apk`。两个安装包均为独立 Java / AndroidX Media3 原生应用，内置来源配置，不需要电脑持续运行或输入网页访问密码。

| 版本 | 应用名称 | applicationId | versionName | versionCode |
| --- | --- | --- | --- | --- |
| 电视 / 盒子 | 幕里 | `org.kongwotv.tv` | `2.16.12` | `2161209` |
| 手机 / 平板 | 幕里 | `org.kongwotv.mobile` | `2.16.12` | `2161209` |

最低支持 Android 5.0（API 21）。使用设备自带解码器，没有限定 ARM32 / ARM64，APK 也可在对应的 x86 Android 环境中安装。

## 更名与覆盖升级

「空我TV」现更名为「幕里」，名称和图标更新，手机 / 平板与电视仍分别沿用 `org.kongwotv.mobile` 和 `org.kongwotv.tv` 包名。直接安装对应版本的新 APK 即可覆盖现有空我TV，无需卸载；观看记录、播放进度和偏好继续使用原来的本机数据。

构建沿用已有本机 release 签名，签名文件和密码不随安装包分发。以后升级幕里时，请继续使用相同 applicationId 和相同签名的 APK，才能覆盖安装并保留本机记录。本次保持 `versionName 2.16.12`，将 `versionCode` 从 2161206 递增为 2161207。

更早的 `org.libretv.tv` 包名属于独立应用，可与幕里共存；其本机数据不会自动迁移。

## 小米电视与电视盒子

1. 将电视 APK 复制到 U 盘，再插入电视。
2. 在文件管理器、媒体中心或电视管家找到 APK 并选择安装。
3. 如系统提示未知来源安装，请允许当前文件管理器安装应用；具体入口可能位于「设置 → 账号与安全 / 隐私与安全 → 安装未知来源应用」。
4. 从电视应用列表打开「幕里」。

电视版同时提供普通应用启动入口和 Android TV 的 Leanback 启动入口，支持没有触摸屏的遥控器设备。首页显示全幅电影背景和横向海报片架，顶部可进入直播、搜索、资料库或设置。左右键切换顶部入口，下键进入内容；确认键选择，返回键退出播放或回到首页。搜索确认后键盘自动收起，焦点停在搜索按钮，左键可重新编辑。

点播全屏时左右键快进 / 快退，菜单键打开选集；直播全屏时上下键换台，菜单键打开频道列表。播放器也提供暂停、上一集 / 下一集、返回换源等按钮。

## 安卓手机与平板

在设备上打开手机 / 平板 APK，按系统提示允许当前浏览器或文件管理器安装应用，再完成安装。打开名称为「幕里」的应用。

底部导航提供首页、直播、影视、资料库和设置。支持竖屏和横屏浏览；手机使用较少卡片列数，平板按可用宽度显示更多列。轻触封面进入适配触摸屏的影片详情，点击播放或剧集即可观看。

播放时自动进入横屏。轻触画面可显示 / 隐藏控制，拖动进度条跳转；顶部的选集 / 频道列表、上一集 / 下一集、暂停和返回按钮均可触摸操作。播放退出后回到原浏览页面。

## 来源与本机记录

内置点播来源为 360资源、如意资源、暴风资源。直播频道快照保存在 APK 内，联网后还会尝试刷新公开频道目录。内置的是地址配置，观看仍需联网；源站可能因时间、地区网络或内容状态出现不可用，遇到失败可重试、切换频道或返回换源。

观看记录与播放进度保存在当前应用的本机数据中。清除应用数据或卸载会清空这些记录。原作者版权、第三方许可证、真实上游链接与图片来源署名均保留。
