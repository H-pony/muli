# Android 产品逻辑与闭环审核（2026-10-23）

范围为统一 Android 手机 / 平板客户端和独立 Android TV 客户端。先检查代码中的发现、搜索、详情、播放、失败恢复、换源、资料库及设置路径，再直接修复下列可确认问题。保留既有工作；没有安装设备、发布、改签名或升级版本号。本报告的界面结论来自代码审查，本轮没有新增真机或模拟器运行截图。

## 已修复

| 问题与影响 | 修复后的行为 |
| --- | --- |
| 同名作品、翻拍和不同来源按片名共用选集记录，会显示或恢复错误的集数。 | 选集按来源接口 + 影片 ID 保存，片名变化不丢记录。旧记录仅在已保存 URL 确实属于当前详情的集表时迁移；无证据不猜测归属。历史卡片显示实际集名。 |
| 换源只返回片名，当前集和观看时间丢失。 | 返回携带影片元数据、集名和位置；稳定 ID 或精确片名 + 年份确认同一作品，已知年份、类型和 ID 冲突时拒绝自动转移。剧集按唯一集名匹配，支持“第02集 / EP02”等写法；电影单集支持不同清晰度名。不能确认时显示说明，主按钮定位至选集区供用户选择，原进度保留。切换搜索词或离开搜索页会清除临时换源上下文。 |
| 加载失败、尚未就绪时采样到的 0 秒可覆盖原断点。 | 首次 READY 前保留待恢复位置；真正播放后快退到 0 秒和播放完毕仍正常保存。重试及换源继续使用保留的断点。 |
| 详情接口未返回请求 ID 时使用第一条，可能打开另一部影片。 | 详情必须精确匹配所选 ID；缺失时进入失败提示，可重试同一来源或搜索其他来源。连续打开详情会取消旧任务，避免过期请求挤占队列。 |
| 清空观看记录只移除列表，旧断点和选集仍残留。 | 手机与电视共用清空逻辑，确认文案明确移除记录、集数和进度，保留倍速、画面等播放偏好。 |
| 从资料库播放后返回，进度与集数不刷新。 | 返回资料库时重新读取播放状态；首页继续观看仍刷新。 |
| “剧情片”“喜剧片”包含“剧”，被误分类为剧集。 | 手机分类筛选和电视首页片架使用统一分类规则；先识别电影类别，综艺、动漫、纪录片保持对应分组。 |
| 推荐去重仅比较片名，同名不同年份/电影与电视剧被吞掉。 | 推荐去重包含片名、年份与媒体类型，保留翻拍和不同媒体作品。 |
| 搜索可能返回 180 条，却固定只显示前 120 条，其余没有入口。 | 两端增加“加载更多”；手机显示当前已展示数量，电视加载后将遥控焦点移至新增第一条。 |
| 详情主按钮固定写“播放 / 继续观看”，电视选集未标识上次集数。 | 按真实状态显示开始播放、继续观看、接续某集或选择剧集，并在两端标记上次集数；换源提示说明可恢复时间或需人工对齐的原因。直播返回使用明确类型标志，不再靠片名判断。 |

## 修改文件

- `app/src/main/java/org/kongwotv/tv/PlaybackState.java`：新增可单测的身份、分类、集名映射和断点保存规则。
- `MainActivity.java`：换源上下文、历史迁移与清空、资料库刷新、详情状态与重试、搜索加载更多。
- `PlaybackActivity.java`：作用域选集键、播放就绪守护、换源状态传递、实际集名持久化。
- `TvRepository.java`：详情 ID 精确匹配、推荐身份去重。
- `TvUi.java`：按作用域读取实际播放状态。
- `MobileUi.java`：搜索加载更多、详情状态、换源说明与选集定位、统一分类。
- `app/src/test/java/org/kongwotv/tv/PlaybackStateTest.java`、`TvRepositoryTest.java`：新增 18 项回归。

```sh
gradle --offline :app:testTvDebugUnitTest :app:testMobileDebugUnitTest \
  :app:lintTvDebug :app:lintMobileDebug \
  :app:assembleTvDebug :app:assembleMobileDebug --console=plain
```

回归覆盖：同名/不同来源隔离、重命名保留身份、选集重排、错误索引边界、加载失败保留断点、真实快退到 0、结束清除断点、换源年份/类型/稳定 ID 冲突、集名对齐与歧义拒绝、单集电影转移、翻拍去重、剧情片/喜剧片分类，以及接口返回错误影片的拒绝行为。
