# 幕里产品与交互规范

适用范围：Android 手机/平板、iPhone/iPad、独立电视客户端、Windows/macOS。桌面内部 React 页面属于客户端实现，不增加独立 Web/PWA 交付物。

## 内容身份与操作语义

- 点播身份以来源和影片 ID 为准；标题仅用于展示和查找，不作为跨影片续播键。
- 推荐到播放必须核对完整片名、已知年份、类型和已提供的稳定 ID。明确冲突的作品不能放在当前影片海报下作为其播放源；元数据不足时提示核对，不自动声称已匹配。
- 详情接口必须返回请求的影片 ID；没有命中进入错误和重试状态，不能取返回列表第一条。
- 未取得剧集时主操作叫“查找播放源”；正在请求时显示明确状态；有有效断点叫“继续观看”；当前集完成后进入下一集；末集完成后“重新播放”显式从零开始。
- 选集、换源、重试、自动代理回退都绑定当前媒体身份。不能把旧媒体的迟到事件写到新集，也不能用加载失败的零秒覆盖旧断点。
- 跨来源换片仅在作品和集数可确认对应时接续；信息不足时保留手动选择和返回入口。
- 只有真实播放后才更新观看历史。清空历史同步清理断点；单条移除、撤销、导入须保持状态一致。

## 页面闭环

| 页面/状态 | 必须提供的下一步 |
| --- | --- |
| 推荐与分类 | 查看详情；长列表有继续加载入口；无结果与网络失败区分 |
| 搜索中 | 进度状态，可用结果逐步显示；新查询不能混入旧查询结果 |
| 搜索失败/来源全失败 | 原地重试和管理播放源；不显示“没有找到”来掩盖请求失败 |
| 未配置/暂停来源 | 直接进入设置；不依赖“右上角”等会随布局改变的位置描述 |
| 无匹配播放源 | 说明未找到本作品；可重新搜索、调整来源或返回 |
| 播放失败 | 重试、换源/线路和返回；保留有效进度 |
| 已看完 | 下一集或重播；不把片尾显示为正常继续观看 |
| 下载暂停/失败 | 每个任务独立保存目标、可继续或重新开始；不能显示没有运行任务的“下载中” |
| 删除/清空 | 说明影响范围；清空需确认；取消为危险操作默认焦点 |

## 视觉和交互

沿用现有黑白品牌、内容主视觉、圆角海报和内容架。基础深色画布 `#08090b`、表面 `#111114`，主文字 `#f5f5f7`；白色用于主播放动作，次操作用中性灰表面。桌面保留用户浅色外观设置。样式维护入口为 `src/app/tv-interface.css`、`apple/Sources/Platform.swift`、Android `TvUi.java` / `MobileUi.java`，避免页面各自引入新主题。

- 正文、片名和当前状态始终可读；缺少评分不能显示虚构分数，缺少图片回退到原封面或明确占位。
- 电脑侧栏、手机底部导航与电视焦点导航分别适配；搜索结果不能把首页错误标为当前页面。
- 按钮文案表示点击后实际发生的动作。加载按钮呈禁用/忙碌状态；失败态必须包含可执行的恢复操作。
- 项目触屏目标：关键操作至少 44pt（Apple）/44 CSS px（共享界面），Android 保持现有原生触控尺寸；不以图标本身大小替代点击区。
- 弹窗只允许最上层接收 Tab/Escape，关闭后恢复触发控件焦点。父子弹窗同时挂载时子层优先；切换弹层保持背景滚动锁，最后一层关闭后释放。
- 控件有可访问名称，选中项和焦点分开表达；键盘、方向键和触摸均保留基本路径。减少动态效果时不强制平滑滚动或缩放动画。
- 验收至少覆盖 320/390/834/1440/1920 宽度、浅色主题、减少动态效果、长标题、空态、错误态和层叠弹窗。桌面内部响应式验证不替代原生触控与遥控器验证。
